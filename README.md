# 📊 RetailIQ - Retail Sales Analytics

## About the Project

RetailIQ is a Data Science and Business
Intelligence project developed using Python.

It analyzes retail sales data to identify
business trends, sales performance,
profitability and customer insights.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Streamlit
- Jupyter Notebook

## Key Features

- Data Cleaning and Preprocessing
- Exploratory Data Analysis
- Sales and Profit Analysis
- Category-wise Analysis
- Regional Performance Analysis
- Customer Segment Analysis
- Interactive Dashboard

## How to Run

1. Clone the repository.
2. Install dependencies:

   pip install -r requirements.txt

3. Run the dashboard:

   streamlit run dashboard/app.py

Data Science | Data Analytics | Business Intelligence
